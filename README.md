# Illustrator：スウォッチ名をCMYK値にする v1.0.1

「Illustrator_スウォッチ名をCMYK値にする.jsx」をIllustratorの「ファイル → スクリプト → その他のスクリプト」から実行してください。対象一覧で通常色・グローバルカラーを複数選択し、「カラー値の丸め」を選んで「実行」を押します。

通常のCMYKスウォッチはswatch.colorから、CMYKグローバルカラーはswatch.color.spot.colorから元色のCMYK値を読み取ります。グローバルカラーの名前はSpot.nameを変更します。

例：`C=0 M=0 Y=100 K=0`。名前は小数第2位まで表示し、`C=12.5 M=0 Y=100 K=0`のように表示します。Illustratorの内部値に含まれる微小な浮動小数点誤差は名前に出しません。名前は31文字以内に収め、連番が必要なときは表示の小数桁数を減らす場合があります。

カラー値の丸めは「変更しない／1刻み／5刻み／10刻み」から選べます。初期値は「変更しない」です。「変更しない」では名前の表示だけを整え、実際のカラー値は保持します。それ以外は実際のCMYK値を四捨五入し、0〜100の範囲に収めてから命名します。5刻みの例：`C=13 M=26 Y=42 K=7` → `C=15 M=25 Y=40 K=5`。

グローバルカラーは、オブジェクト側の濃度によらず元色の値を使います。丸めはその元色を使っている図形や文字にも反映され、オブジェクト側の濃度は保持します。通常スウォッチはすでに塗られた非グローバルのオブジェクトと連動しないため、スウォッチだけを丸めます。プロセス／特色の種類とグローバル設定は変更しません。

同名になる場合は` (2)`、` (3)`などを付けます。スウォッチは統合しません。RGB、グレー、Lab、特色、レジストレーション、なし、パターン、グラデーションは対象外です。RGBからCMYKへの変換は行いません。

エラーの場合は、通常色／グローバルカラーと処理段階を結果に表示します。実際に変更を試みた色は元の値と名前への復元を試み、復元できなかった場合はその内容も表示します。
